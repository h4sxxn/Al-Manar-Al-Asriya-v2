# Al Manar Al Asriya — Website v2

A new, animation-rich one-page marketing site for **Al Manar Al Asriya — General Trading & Contracting Co.**, a heavy machinery rental company in Kuwait (since 2002).

> This is a separate project. The original site lives in the `Al-Manar-Al-Asriya` repository and is not affected by this code.

## Highlights

- **React + Vite + Framer Motion** — staggered hero typography, parallax, scroll-reveal sections, animated counters, amber marquee ticker, spotlight-hover fleet cards, animated FAQ accordion
- **Fully bilingual EN / AR** with a proper RTL layout and Arabic typeface (IBM Plex Sans Arabic)
- **Fleet → quote flow**: tapping a machine pre-fills the quote form, which opens WhatsApp (+965 9901 5863) with the request composed
- Custom typographic logo mark (SVG), dark industrial design system with a safety-amber accent

## Develop

```bash
npm install
npm run dev
```

## Build & deploy

```bash
npm run build
```

The production build is published to GitHub Pages from the `gh-pages` branch of this repository.
